# TrustArchive Releases

Public release binaries for the **TrustArchive** desktop application.

Each release on this repo contains the official Windows `.msi` (and eventually
macOS `.dmg`) installer for that version. Source code is hosted in a separate
private repository.

→ See the [Releases](https://github.com/apvera-admin/trustarchive-releases/releases)
page for downloads.

Visit [trustarchive.co](https://trustarchive.co) for product information.
